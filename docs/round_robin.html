Round-Robin Scheduler

Cyclic, fixed-rotation assignment — src/elevator_sim/schedulers/round_robin.py

How it works

  • Cyclic assignment. Elevators are handed requests in a fixed rotation: elevators[next_index % n], and the pointer always advances.
  • No positional awareness. Assignment doesn't factor in any elevator's current position, remaining stop queue, or capacity.
  • One exception: same-tick batching. Requests that arrive in the same tick and head the same direction are bucketed onto the car the pointer is currently on, instead of each claiming a fresh car off the rotation.
  • Why the exception exists. Without it, a burst of simultaneous compatible requests would pointlessly occupy every elevator at once.
  • Wait estimate. Always the naive distance guess: abs(elevator.current_floor − request.source).

Diagram

Top: absent batching, every request advances the pointer to the next car. Bottom: R5 and R6 arrive on the same tick heading the same direction, so both land on E1 and the pointer advances only once; R7 arrives a tick later and gets the next car, E2.
